# quant-factor-backtest

A 股 ETF 因子研究与策略回测个人项目。基于公开行情数据，完成**因子检验（Rank IC/ICIR）→ 策略构建 → 回测评估 → 样本外验证**的完整量化研究闭环。

## 研究结论（2020-11 ~ 2026-09，前复权日线）

### 实验一：黄金 ETF 双均线趋势择时（MA20/MA120）

| 指标 | 择时策略 | 买入持有 |
|---|---|---|
| 年化收益（全样本） | 18.1% | 18.9% |
| Sharpe（全样本） | **1.13** | 1.08 |
| 最大回撤（全样本） | **-24.9%** | -30.5% |
| Sharpe（样本外 2024+） | **1.63** | 1.33 |

结论：趋势跟踪在趋势性资产上有效，策略以小幅收益为代价显著改善风险调整后收益与回撤。

### 实验二：ETF 篮子截面反转因子（120 日）+ Top-2 轮动

| 指标 | 全样本 | 样本外 2024+ |
|---|---|---|
| Rank IC 均值 | 0.10 | **0.20** |
| ICIR | 0.19 | 0.34 |
| IC 胜率 | 60.9% | 64.5% |
| 轮动策略年化 / Sharpe | **15.3% / 0.65** | 41.0% / 1.51 |
| 等权基准年化 / Sharpe | 6.6% / 0.32 | 23.0% / 0.92 |

结论：A 股 ETF 截面在中周期（120 日）呈显著反转效应，因子样本外表现强于样本内。

### 参数扫描发现（研究过程记录）

- 双均线择时在沪深300上全参数组亏损，在创业板/中证500上弱有效，在黄金上稳定有效 → 趋势策略有效性依赖资产的趋势性。
- 截面因子：短周期（5-20 日）动量/反转 IC 均接近 0；中周期（40-120 日）反转 IC 稳定为正（0.08~0.10）→ A 股中周期反转效应。

> 免责声明：参数在全样本上选取，存在样本内选择偏差；结果仅用于方法论演示与学习，不构成投资建议。

## 方法要点

- **防前视**：T 日收盘出信号，T+1 日生效；因子与未来收益严格错位。
- **样本外验证**：2024-01-01 之后为样本外区间，所有指标分段输出。
- **指标口径**：日频收益，年化 252 个交易日，无风险利率取 0。

## 数据

7 只跨资产 ETF，前复权日线（腾讯财经公开接口）：
沪深300(510300)、中证500(510500)、中证1000(512100)、创业板(159915)、科创50(588000)、黄金(518880)、银华日利(511880)。
